
**第一批：最值得做的功能**

1. 日报 AI 解读

```
总结今天日报
今天最重要的三条
瑞希，用三句话讲今天日报
```

实现思路：读取最新日报 Markdown，把它作为上下文发给 DeepSeek，再返回简短总结。

价值：日报从“给你看”变成“给你讲”。

2. 历史日报搜索

```
搜索日报 SQLite
搜索日报 Rust
```

实现思路：扫描 `data/summaries` 下所有中文日报，按关键词匹配标题、摘要、标签，返回相关条目和原文链接。

价值：日报不再是读完就丢。

3. 关键词订阅提醒

```
订阅关键词 OpenAI
订阅关键词 安全
取消订阅关键词 OpenAI
我的关键词
```

实现思路：为每个群保存关键词列表。每天日报生成后，自动检查关键词命中的资讯，单独推送。

价值：群成员可以只关注自己关心的内容。

4. 多群差异化配置

```
日报设置 条数 5
日报设置 时间 09:00
日报设置 专题 开
日报设置 专题 关
日报设置 查看
```

实现思路：给每个群单独保存配置，不再所有群共用一个 `defaultItems` 和 `scheduleTime`。

价值：不同群可以有不同的日报体验。

**第二批：常见的完整机器人功能**

5. 每日早晚安

```
早安
晚安
```

也可以定时自动发送，例如：

```
07:30 早安 + 昨日日报摘要
23:00 晚安 + 明日竞赛提醒
```

6. 新成员欢迎语

机器人检测到新人进群后，瑞希自动欢迎，并发送 `机器人帮助`。

7. 竞赛/比赛提醒

```
竞赛提醒
下次比赛
订阅 ICPC
```

实现思路：内置 ICPC、蓝桥杯、Kaggle、CTF 等常见比赛时间表，每天检查并提醒。

8. 链接卡片解析

```
B站链接
GitHub 链接
```

发送链接后机器人自动返回标题、简介、作者、封面等摘要。

9. 每日 GitHub 精选

```
今日 GitHub
GitHub 搜索 rust
```

调用 GitHub API 返回今日热门项目、标题、Star、简介。

10. 群待办/提醒

```
提醒我 30分钟后 喝水
待办 添加 写实验报告
待办 查看
```

11. 随机技术小知识

```
来点干货
今日一句
```

从日报或内置知识库随机抽取一条技术知识。

**第三批：让瑞希更像“人”**

12. 主动参与群聊

启用 `chatluna-character`，只在单个测试群开启白名单，先只回复被 @ 和叫名字的消息，稳定后再开启低频主动发言。

13. 用户偏好记忆

```
我喜欢 Rust
我关注安全方向
```

机器人记住偏好，日报解读时优先讲相关新闻。

14. 日报周报

```
本周日报
周报
```

每周日生成一周日报汇总。

15. 语音回复

接入 TTS 服务后：

```
瑞希，用语音说今天的重点
```

**推荐实施顺序**

先做第一批，原因是：

- 全部基于现有日报数据，不需要新外部服务
- 能直接提升日报价值
- 不增加明显成本
- 群成员使用门槛低

我建议按这个顺序实现：

```
1. 日报 AI 解读
2. 历史日报搜索
3. 关键词订阅提醒
4. 多群差异化配置
```

这四个功能做完，机器人就已经从“日报推送器”升级成“能对话、能搜索、能定制”的 QQ 助手。你确认后，我可以直接从第一个开始写。
