# 隐写术入门

> 最通俗的理解：**加密是写密信，隐写是用隐形墨水写普通的信。**

---

## 先讲个故事

你和一个朋友被抓住了，看守说你们可以通信，但每封信我都会看。

**加密的做法**：你写一堆乱码——看守一看就知道是密文，虽然看不懂但知道你们在密谋。

**隐写的做法**：你写今天天气真不错，中午吃的面条，隔壁老王的猫又跑了——看守看完觉得废话连篇。但你朋友知道，每句话第一个字拼起来就是今晚在老地方见。

这就是隐写的本质：**信息藏在看起来正常的东西里，外人根本不知道有信息存在。**

---

## 隐写到底是什么

> **隐写 = 把秘密数据藏到一个正常载体里，让载体表面上看起来没有任何异常。**

三个要素：

```
载体 (Cover)     —— 看起来正常的东西（图片、文字、音频...）
消息 (Message)   —— 你想藏的秘密
嵌入算法         —— 怎么把消息塞进去不被人发现
```

---

## 第一个例子：藏在文字里

### 空格编码

每个单词后的空格数量编码 0 和 1：

单个空格 = bit 0，两个空格 = bit 1。

这个例子揭示了隐写的核心思想：**载体 = 正常通信，数据藏在载体的冗余部分里**。

---

## 为什么人眼分不出区别

一张 1920x1080 的图片有 6.2MB 的信息量，但人眼能区分的远没有那么多。

一个像素的红色是 253(11111101)，改成 252(11111100)——你看不出来。

这多出来的人眼看不出来的精度，就是 LSB 隐写的藏身之处。

---

## 从零实现图片 LSB 隐写

### 藏入

```python
def encode_lsb(image, message, output):
    from PIL import Image
    import numpy as np
    img = Image.open(image)
    pixels = np.array(img)
    msg = message + "\x00"  # 结束标记
    bits = "".join(format(ord(c), "08b") for c in msg)
    flat = pixels.flatten()
    for i, bit in enumerate(bits):
        flat[i] = (flat[i] & 0xFE) | int(bit)
    Image.fromarray(flat.reshape(pixels.shape)).save(output)
```

核心就一行：
```
flat[i] = (flat[i] & 0xFE) | int(bit)
```
- 0xFE = 11111110，把最后一位清空
- | int(bit) = 把消息位写进去

### 提取

```python
def decode_lsb(image):
    from PIL import Image
    import numpy as np
    flat = np.array(Image.open(image)).flatten()
    bits = "".join(str(p & 1) for p in flat)
    chars = []
    for i in range(0, len(bits), 8):
        c = chr(int(bits[i:i+8], 2))
        if c == "\x00": break
        chars.append(c)
    return "".join(chars)
```

改前 R=11010101(213)，改后 R=11010100(212)，变化 0.4%——看不出来。

## 简单检测方法

正常图片的 LSB 分布接近 50% 随机。不随机就有问题：

```python
def detect(image):
    import numpy as np
    from PIL import Image
    lsb = np.array(Image.open(image)) & 1
    r = np.sum(lsb) / lsb.size
    return abs(r - 0.5) > 0.1  # True = 有隐写
```

---

## 你已掌握的

- 隐写 = 藏存在，加密 = 藏内容
- 载体 + 消息 + 算法 = 三要素
- LSB = 把数据写入像素最后 1 bit
- 人眼精度有限 = 隐写空间
- 检测 = 统计 LSB 分布
