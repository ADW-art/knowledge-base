# VPN 是什么

> **一句话**: VPN = 在你和另一台机器之间挖一条**加密隧道**，让你感觉坐在那台机器的局域网里。

---

## 先讲个场景

你在家想访问公司内网的文件服务器 `192.168.1.100`——这个 IP 在公司局域网里才有，外网根本访问不到。

VPN 做的事：

```text
你的电脑 ─── 加密隧道 ─── 公司 VPN 服务器 ─── 公司内网
                              ↓
                        你能访问 192.168.1.100 了
                        就像你的电脑坐在公司里一样
```

**VPN 给你的不是"能翻墙"，而是一个"虚拟的局域网身份"。**

---

## 核心原理：隧道 + 加密

### 隧道（Tunneling）

把你的网络包**整个装进另一个网络包**里发送：

```text
原始包：
[ 源IP: 你的电脑 | 目标IP: 192.168.1.100 | 数据 ]

封装后（进入隧道）：
[ 源IP: 你的电脑 | 目标IP: VPN服务器 | 
    [封装的内容: 原始包] 
]
```

VPN 服务器收到后拆开外层，取出原始包，再发到内网。

就像你把一封信装进另一封信里寄出去，中间人只看到外层信封上的地址，看不到里面的内容。

### 加密

隧道里的所有数据都是加密的——中间人截获了也只能看到乱码。

```text
你的数据 → 加密 → 隧道 → VPN服务器 → 解密 → 目标网站
                                          解密后才是明文
```

## VPN vs 代理（Clash）

| | VPN | Clash / 代理 |
|--|-----|-------------|
| 层面 | **系统层面**（虚拟网卡） | **应用层面**（某个端口） |
| 流量 | **所有流量**都走 | 只有配置了走代理的才走 |
| 实现 | 创建虚拟网卡，改路由表 | 监听端口，应用主动连接 |
| 协议 | WireGuard / OpenVPN / IPSec | vmess / shadowsocks / trojan |
| 灵活性 | 全有或全无，或按路由分 | 可按**域名**精细控制 |
| 典型场景 | 连公司内网 | 科学上网 |

```text
VPN 的视角：整个设备的流量
  你的电脑 → 虚拟网卡 → VPN → 互联网

Clash 的视角：每个连接单独判断
  你的电脑 → 浏览器请求 github.com
             → Clash 判断"走代理"
             → 连接代理服务器
  你的电脑 → 浏览器请求 baidu.com
             → Clash 判断"直连"
             → 直接连接
```

### 关键技术差异

**VPN 工作在网卡层（L3）**：
```
你的电脑          VPN 服务器
┌──────┐         ┌──────┐
│ 虚拟网卡 │←────→│ 虚拟网卡 │
│ 10.0.0.2│      │10.0.0.1│
└──────┘         └──────┘
所有经过网卡的流量自动加密发送
```

**Clash 工作在应用层（L5-L7）**：
```
你的电脑
┌──────────┐
│ 浏览器 → │→ 127.0.0.1:7890
│ 游戏 →   │→ 直连（不走代理）
│ 微信 →   │→ 直连（不走代理）
└──────────┘
只有配置了代理的应用才走
```

## VPN 的三种常见协议

### 1. OpenVPN

最老牌、最通用。开源，几乎所有平台都支持。

```text
优点：兼容性最好，能过大多数防火墙
缺点：配置复杂，速度较慢（TCP over TCP 效率低）
端口：1194 UDP（默认）
```

### 2. WireGuard（现代、推荐）

2018 年才出来的新协议，代码只有 4000 行，比 OpenVPN 的几十万行小得多。

```text
优点：
  - 速度极快（内核态运行）
  - 连接秒建（不像 OpenVPN 要握手好几轮）
  - 代码少，安全审计容易
  - 移动端切换网络不中断

缺点：
  - UDP 纯连，容易被 QoS
  - 需要服务器支持

一句话：WireGuard = VPN 界的"更快、更小、更安全"
```

### 3. IPSec（企业级）

大公司用的，路由器自带支持。

```text
优点：不用装客户端，路由器直接配
缺点：配置复杂到令人崩溃，容易被墙识别
```

## 你用的"梯子"是 VPN 吗？

**不是。** 你用的 Clash Party + 机场订阅是**代理（Proxy）**，不是 VPN。

但很多人的"梯子"App 其实是**翻墙 VPN**——它们在手机/电脑上创建一个虚拟网卡，把所有流量加密后送到境外服务器。

两者的界限现在很模糊：

```text
Clash 的 TUN 模式：
  创建虚拟网卡 → 所有流量截获 → 按规则分代理/直连
  → 这就跟 VPN 一样了，但多了规则判断

WireGuard + 路由表：
  只让被墙的 IP 走 VPN，国内 IP 直连
  → 这就跟 Clash 一样了，但用 VPN 技术实现
```
