# Universal Diagnostic Tutor Skill 使用指南

> 一个诊断优先的 AI 导师 Skill。先判断你卡在概念、符号、方法还是推理，再讲最小有效下一步。

## 快速开始

Codex 新对话 → 点击 Skill Picker → 选择对应 Tutor 入口 → 用自然语言说你的学习问题。

## 六个入口

| 入口 | 场景 | 示例 |
|------|------|------|
| **Universal Diagnostic Tutor** | 不确定用哪个，或一般 STEM/AI-CS 学习问题 | "我零基础，矩阵乘法到底在干什么？先解释对象和符号" |
| **Tutor Learn Path** | 学大主题、做学习计划、安排备考路线 | "我会一点 Python 但数学弱，想系统入门机器学习，帮我出路线" |
| **Tutor Practice** | 做题、批改、错因分析、卡点诊断、判断能否进下一阶段 | "我刚学导数，出一道基础题，等我答完再批改" |
| **Tutor State Card** | 保存进度、跨对话继续 | "帮我生成学习状态卡，下次从链式法则这个卡点继续" |
| **Tutor Resource Scan** | 找可信课程、文档、教材方向 | "我想补线代，推荐适合初学者的可信课程方向" |
| **Tutor Visualize** | 用图/表/流程图理解概念 | "画图解释矩阵乘法为什么可以看成空间变换" |

## 文字快捷方式

在 Codex 对话里可以手动输入这些别名（非命令行，只是意图提示）：

| 输入                                            | 效果                              |
| --------------------------------------------- | ------------------------------- |
| `/tutor`                                      | 通用诊断式教学                         |
| `/study-plan` `/learn-anything`               | 学习路线/计划                         |
| `/practice` `/diagnose-gap` `/mistake-review` | 练习+批改+诊断                        |
| `/state-card`                                 | 生成学习状态卡                         |
| `/resource-scan`                              | 找学习资源                           |
| `/visualize`                                  | 画图理解                            |
| `/exam-track`                                 | 备考规划(Learn Path)或刷题复盘(Practice) |

## 工作流

```
提出问题 → AI诊断科目/知识点/卡点 → 讲最小有效一步
→ 出检查题 → 你作答 → 定性批改 → 修复卡点 → 判断能否进阶
```

## 状态卡用法

1. 学完一段后说"帮我生成学习状态卡"
2. 复制生成的卡片
3. 下次新对话 → 粘贴卡片 → 说"根据这张状态卡继续，不要从头讲"

## 适用范围

最强：大学 STEM / 数学 / 编程 / 算法 / AI-ML / 系统 / 网络 / 物理 / 信号 / 工程基础
可用：其他学科（人文/语言/经济/法律），但保持 modest effort

## 不会做

- 不记隐藏状态（状态靠卡片手动传递）
- 不保证分数、不预测考试、不泄漏真题、不押题
- 不替代专业医疗/法律/财务建议
